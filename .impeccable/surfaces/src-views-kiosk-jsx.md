Scope: kiosk + mobile record screen (Experience/Operate hybrid) and admin archive (Operate).

## Direction contract
THESIS: The category standard played straight: exhibition image leads, one unmistakable record control, nothing else competes. Refuses decorative rainbow waveforms, emoji, and generic dashboard cards.
OWN-WORLD: Kiosk near-black ground, exhibition image full-bleed top, white type in the platform face, accent = exhibition colour (default record red). Admin: neutral light ground, hairline dividers, near-black primary buttons, tabular figures.
STORY: Visitor sees the work, reads one line, taps, speaks, sees honest confirmation. Organizer scans, listens, transcribes, exports, reads participation by artwork.
FIRST VIEWPORT: Kiosk portrait: image top 50%, title block, live scrolling waveform with playhead, 0:00 timer, 120px record control centred low. Landscape: image left half, controls right. Admin: top bar with exhibition name and four tabs, filter row, list of recordings each drawn as its own waveform.
FORM: canon (standard pulito), user-chosen standing exit; seed: bc997d59cc5776c3
SIGNATURE: every recording drawn as its real waveform (peaks captured while recording), live in kiosk, as the play scrubber in admin.
